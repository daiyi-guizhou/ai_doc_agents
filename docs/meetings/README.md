# meetings/ — 会议纪要

放会议记录。命名强制 `YYYY-MM-DD-kebab-slug.md`，天然按时间排序、可追溯。

- 命名：`YYYY-MM-DD-kebab-slug.md`
- 必须 frontmatter：`type: meeting`
- 纪要要点：结论、待办（含 owner 与 deadline）、未决项
- 周期性会议可用固定 slug，如 `2026-08-05-weekly.md`
